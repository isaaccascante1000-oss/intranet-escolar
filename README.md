# Intranet Escolar — Centro Educativo Público

Prototipo funcional de una **Intranet Escolar** orientada a instituciones de educación pública. Facilita la interacción entre la administración, el personal docente, el estudiantado y los encargados de familia en una plataforma web accesible.

---

## Módulos Principales

- **Gestión de Usuarios:** Alta, baja y actualización de perfiles de usuario por la administración.
- **Módulo Académico:** Registro y consulta de calificaciones y asistencia según el rol del usuario.
- **Tablón de Comunicados:** Espacio público para difundir avisos y circulares institucionales.
- **Control de Acceso por Rol:** Vistas adaptadas a las credenciales autenticadas (`admin`, `docente`, `estudiante`).

---

## Requisitos de Ejecución

Para desplegar y visualizar este proyecto localmente, solo necesitas un navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge) y un editor de código como Visual Studio Code.
