# Lista de Requerimientos y Tareas

Seguimiento detallado de las funcionalidades implementadas en el proyecto **Intranet Escolar**.

---

## Requerimientos Funcionales

- [x] **Autenticación por roles:** Pantalla de inicio de sesión que distingue entre `admin`, `docente` y `estudiante`.
- [x] **Gestión de usuarios:** Módulo exclusivo para que la administración agregue, liste y elimine usuarios.
- [x] **Módulo académico:** Interfaz para que los docentes registren calificaciones y los estudiantes consulten su rendimiento.
- [x] **Tablón de comunicados:** Publicación y lectura de noticias o circulares institucionales.
- [x] **Filtro de vistas por rol:** Restricción de interfaz para que cada perfil vea únicamente lo que le corresponde.

---

## Requerimientos No Funcionales

- [x] **Estructura semántica:** Código HTML5 y CSS organizados limpiamente dentro del directorio `src/`.
- [x] **Persistencia simulada:** Manejo de sesiones y datos dinámicos mediante `localStorage`.
- [x] **Documentación técnica:** Archivos `.md` estructurados siguiendo estándares GFM en la raíz y en `docs/`.
- [x] **Versionado progresivo:** Historial de commits ordenado utilizando Conventional Commits.
