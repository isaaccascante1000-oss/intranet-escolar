# Historial de Cambios (Changelog)

Todos los cambios notables en este proyecto serán documentados en este archivo.

---

## [1.0.0] - 2026-08-12

### Añadido
- Prototipo funcional completo de la Intranet Escolar en la carpeta `src/`.
- Módulo de autenticación por roles (`admin`, `docente`, `estudiante`).
- Módulo de gestión de usuarios (alta, lista y baja) para administración.
- Módulo académico para registro y consulta de calificaciones.
- Tablón de avisos y comunicados oficiales del centro educativo.

---

## [0.2.0] - 2026-08-12

### Añadido
- Creación de la estructura base de documentación en Markdown (`README.md`, `CONTRIBUTING.md`, `CHANGELOG.md`).
- Definición de credenciales de prueba para la autenticación simulada por roles.

---

## [0.1.0] - 2026-08-12

### Añadido
- Inicialización del repositorio Git en la rama `main`.
- Creación del archivo de memoria de la IA (`AGENTS.md`) con las 7 secciones obligatorias.
